# 📂 База пользователей FunPay

Публичный датасет с идентификаторами и никами пользователей торговой площадки [FunPay](https://funpay.com).
Собран для удобного поиска страниц пользователей по нику или ID.

> **Актуальность:** данные актуальны на **7 июля 2026 года**.

---

## 🔎 Зачем это нужно

Иногда нужно найти страницу пользователя на FunPay, но:

- вы **знаете ник**, но не можете найти человека через встроенный поиск;
- ник был **изменён**, а старая ссылка уже не открывается;
- вы хотите **проверить**, существует ли аккаунт с таким именем;
- нужно **массово сопоставить** ники и ID для аналитики или парсинга.

Этот список позволяет быстро найти нужный ID по нику (или наоборот) обычным текстовым поиском (`Ctrl + F`).

---

## 📄 Файл

`users.txt` — полный список пользователей. Каждая строка — один пользователь в формате:

```
ID | Ник | Ссылка
```

Пример:

```
1 | Dipper | https://funpay.com/users/1/
20572056 | akrobat34 | https://funpay.com/users/20572056/
```

> ⚠️ **Файл весит более 1 ГБ** и может не открыться в стандартном «Блокноте» (или он сильно зависнет). Используйте редактор, рассчитанный на большие файлы, например **Sublime Text**, **Notepad++**, **VS Code** или **EmEditor**.

---

## 🚀 Как пользоваться

**Найти страницу по нику:**
1. Откройте `users.txt`.
2. Нажмите `Ctrl + F` и введите ник.
3. Скопируйте ссылку из найденной строки.

**Открыть страницу по ID напрямую:**

```
https://funpay.com/users/ID/
```

Замените `ID` на нужный номер, например `https://funpay.com/users/12345/`.

---

## ⚠️ Важно

- Все данные собраны **из открытых источников** — публичных страниц профилей FunPay, доступных без авторизации.
- Датасет **не содержит** личной, контактной или платёжной информации — только публичные ID, ники и ссылки на профили.
- Ники на FunPay могут меняться, поэтому со временем часть данных может устареть. ID пользователя при этом остаётся постоянным.
- Материал предоставляется «как есть» и предназначен для справочных и исследовательских целей.
